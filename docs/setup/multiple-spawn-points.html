複数の出現地点を設定する

SpawnObjectExt では、単一の Spawn Point に加えて、複数の Spawn Points を使用できます。

Spawn Points を利用すると、指定された出現地点のうち、Spawnを実行したプレイヤーから最も近い地点にアイテムが出現するようになります。

設定手順​

  1. シーンに出現地点を表すGameObjectを複数作成する
  2. 各GameObjectの位置と回転を調整する
  3. SpawnObjectExt の出現先を 複数 に切り替える
  4. Spawn Points に作成したTransformを登録する
  5. Spawn Points に未設定の要素がないことを確認する

Spawn時には、操作したプレイヤーの現在位置から最も近い有効な Spawn Point が選ばれます。位置だけでなく、選ばれた地点の回転も反映されます。

出現先の優先順位
  1. Move Item To Hand が有効な場合は、スイッチに近い方の手
  2. 出現先が 単一 の場合は、Spawn Point
  3. 出現先が 複数 の場合は、プレイヤーに最も近い Spawn Point
  4. 有効な出現先がない場合は、Poolに登録されたオブジェクトの初期位置

Move Item To Hand が有効な間は、単一・複数どちらの出現先設定も使用されません。

動作確認​

  1. 離れた位置に2つ以上の Spawn Point を配置する
  2. いずれかの地点に近づいてSpawnスイッチをInteractする
  3. 最も近い地点へアイテムが移動することを確認する
  4. 別の地点へ移動して、選ばれる出現先が変わることを確認する

移動が正しく反映されない場合は、通常オブジェクトでは Spawn Delay Frames、Helperコンポーネントを使用しているアイテムでは Move Delay を調整してください。

各項目の詳細は SpawnObjectExt の設定項目 をご覧ください。
