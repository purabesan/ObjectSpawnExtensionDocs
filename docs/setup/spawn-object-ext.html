Spawnスイッチを作る

Spawnスイッチは、VRCObjectPool に登録されたオブジェクトを1つずつ表示します。Extension版では、SpawnObjectExt を使用します。

設定手順​

  1. Hierarchyにスイッチ用のGameObjectを追加する
  2. Interact判定に使うColliderを追加する
  3. SpawnObjectExt コンポーネントを追加する
  4. VRC Object Pool に、作成した VRCObjectPool オブジェクトを登録する
  5. 出現先を 単一 にする
  6. 必要に応じて Spawn Point を設定する

スイッチをInteractすると、Pool内のオブジェクトが順番に表示されます。

出現位置​

出現位置を表すGameObjectを用意し、そのTransformを Spawn Point へ設定すると、位置と回転が反映されます。

Move Item To Hand を有効にすると、スイッチに近い方の手へ出現します。この場合、Spawn Point は使用されません。

複数の出現地点を使う場合は、基本動作を確認してから 複数の出現地点を設定する へ進んでください。

動作確認​

  1. ワールドを起動する
  2. SpawnスイッチをInteractする
  3. Pool内のオブジェクトが1つ表示されることを確認する
  4. Spawn Point または Move Item To Hand を設定した場合は、指定した位置へ移動することを確認する

各項目の詳細は SpawnObjectExt の設定項目 をご覧ください。

動作を確認できたら、Returnトリガーを作る へ進んでください。
