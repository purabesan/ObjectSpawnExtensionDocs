Object Spawn Extension

Object Spawn Extensionは、Object Spawn Systemに追加機能を提供する拡張パックです。

配布unitypackageにObject Spawn System本体も同梱されているため、Object Spawn Extensionだけで必要なコンポーネントをまとめて導入できます。

追加される機能​

  • 複数の出現地点から、プレイヤーに最も近い地点を選んでSpawnする
  • Spawnするアイテムごとに、移動先を基準とした位置・回転オフセットを設定する
  • ObonEasy v3.0以降の TrayItem / TrayItemManual に設定された高さ・回転オフセットをSpawn時に流用する
  • Pickupが子階層にある複雑な構造のアイテムをSpawn・Returnする
  • へのごはん様 製の食べられるギミック付きアイテム（v7.x.x / v8.x.x系）をSpawn・Returnする
  • Spawn・Returnの成功時に、任意の UdonBehaviour へカスタムイベントを通知する
  • 既存の SpawnObject と ReturnObject をExtension版へ自動移行するエディタツール

動作確認環境​

  • Unity 2022.3.22f1
  • VRChat SDK - Worlds 3.10.4

最初に 導入と動作確認 を読み、同梱のサンプルシーンで動作を確認してください。

基本構成​

役割コンポーネント動作
Spawn拡張SpawnObjectExt複数の出現地点、複雑なアイテム、イベント通知に対応する
Spawn位置・回転補正SpawnOffsetアイテムごとに移動先からの位置・回転オフセットを設定する
ObonEasy連携（任意）TrayItem / TrayItemManualObonEasy v3.0以降のオフセット設定をSpawn時に流用する
Return拡張ReturnObjectExt子PickupからPoolへ登録したルートを特定し、非表示にする
汎用HelperコンポーネントCompSpawnHelper複雑な構造のアイテムを移動・リセットする
専用HelperコンポーネントHGSpawnHelperへのごはん様製アイテム（v7.x.x / v8.x.x系）を移動・リセットする

ObonEasyは必須ではありません。連携機能を使用する場合のみ、ObonEasy v3.0以降を導入してください。詳しい検索対象と優先順位は、Spawn時の位置・回転を調整する をご覧ください。

Object Spawn Systemとの関係​

Object Spawn Extensionは、同梱されているObject Spawn Systemの SpawnObject と ReturnObject を継承しています。VRCObjectPool、ResetSwitch、Layerなどの基本的な設定方法は共通です。

Object Spawn Systemを初めて利用する場合は、基本セットアップ から順に設定してください。Extension版では、Spawnスイッチに SpawnObjectExt、Returnトリガーに ReturnObjectExt を使用します。

Object Spawn System本体の詳細は、Object Spawn System説明書 でも確認できます。
