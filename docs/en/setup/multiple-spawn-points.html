Configure multiple spawn points

In addition to a single Spawn Point, SpawnObjectExt can use multiple Spawn Points.

Setup​

  1. Create multiple GameObjects in the scene to represent spawn points
  2. Adjust the position and rotation of each GameObject
  3. Change the destination mode on SpawnObjectExt to 複数 (Multiple)
  4. Register the Transforms in Spawn Points
  5. Confirm that Spawn Points contains no unassigned entries

When spawning, the nearest valid Spawn Point to the player operating the switch is selected. Both the position and rotation of the selected point are applied.

Destination priority
  1. If Move Item To Hand is enabled, the hand closer to the switch
  2. If the destination mode is 単一 (Single), Spawn Point
  3. If the destination mode is 複数 (Multiple), the Spawn Point nearest to the player
  4. If no valid destination exists, the initial position of the object registered in the Pool

While Move Item To Hand is enabled, neither the single nor multiple destination setting is used.

Test the behavior​

  1. Place at least two Spawn Points far apart
  2. Move near one point and Interact with the Spawn switch
  3. Confirm that the item moves to the nearest point
  4. Move near another point and confirm that a different destination is selected

If movement is not applied correctly, adjust Spawn Delay Frames for normal objects or Move Delay for items using a helper component.

See SpawnObjectExt settings for details about each field.
