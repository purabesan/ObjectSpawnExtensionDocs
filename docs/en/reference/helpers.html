Helper component settings

CompSpawnHelper​

FieldTypeDescription
Return Base GoGameObjectPickup-side child GameObject that enters the Return trigger
Moves after Spawn and has its position reset after Return
Move DelayfloatNumber of seconds to wait between spawning and moving
Default: 1

Add CompSpawnHelper to the parent root GameObject registered in VRCObjectPool. In Return Base Go, assign the Pickup-side child GameObject that enters the Return trigger.

If Return Base Go contains VRCObjectSync, the helper uses FlagDiscontinuity and synchronized movement. On Return, it resets the position with Respawn.

Without VRCObjectSync, the helper moves the Transform directly and restores the position and rotation saved at world startup on Return.

HGSpawnHelper​

FieldTypeDescription
HG BaseGameObjectGameObject containing the corresponding Base script
HG SyncGameObjectGameObject containing the VRCObjectSync used for movement
Move DelayfloatNumber of seconds to wait between spawning and moving
Default: 1

HGSpawnHelper finds the corresponding UdonSharpBehaviour on HG Base and uses the VRCObjectSync on HG Sync for movement.

Ownership​

When a client obtains ownership of a helper component, it also obtains ownership of the GameObject configured as the movement target. In a multi-user world, test Spawn, Return, and respawning with two clients.

Component placement​

Add either helper component to the same root GameObject registered in VRCObjectPool. A configuration containing both helper components on one root is not supported.
