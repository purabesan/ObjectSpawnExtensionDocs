Installation and testing

Requirements​

Prepare a Worlds project created with VCC (VRChat Creator Companion).

ObonEasy v3.0 or later is required to reuse offsets configured on its TrayItem / TrayItemManual. You do not need to install ObonEasy when this integration is not used.

Back up your project​

Back up your Unity project

Create a backup before importing Object Spawn Extension so you can return to the previous state if a problem occurs.
Close Unity, save the entire project folder as a ZIP file, and store it separately from the original project.

ALCOM, an unofficial alternative to VCC, can create a ZIP backup of a Unity project with one button.

Import​

  1. Import the Object Spawn Extension unitypackage
  2. Confirm that PurabeWorks/ObjectSpawn exists in the Project window
  3. Confirm that PurabeWorks/ObjectSpawnExtension exists in the Project window
  4. Confirm that the Console contains no compilation errors

Test the sample scene​

  1. Open PurabeWorks/ObjectSpawnExtension/SampleScene.unity
  2. Start the world with a VRChat SDK testing feature
  3. Interact with a Spawn switch and confirm that an item appears
  4. On a switch with multiple spawn points, confirm that the item appears at the point nearest to the player
  5. Place a child Pickup in a Return trigger and confirm that the entire item becomes hidden
  6. In a sample with event notifications configured, confirm that the Unity Console displays a received-event log

Next steps​

If this is your first time using Object Spawn System​

  1. Prepare a Pickup for spawning
  2. Configure VRCObjectPool
  3. Create a Spawn switch
  4. Create a Return trigger
  5. If needed, create a Reset switch

If the scene already uses the standard Object Spawn System​

See Migrate from Object Spawn System.

If you want to configure Extension features​

  • For multiple spawn points, see Configure multiple spawn points
  • For per-item position and rotation offsets or ObonEasy offset settings, see Adjust position and rotation when spawning
  • When a Pickup is on a child GameObject, see Configure a complex Pickup
  • For items made by Heno Mohesan Gohan, see Configure an item made by Heno Mohesan Gohan
  • To call custom logic, see Configure event notifications
